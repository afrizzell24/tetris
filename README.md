This program runs a simplified version of Tetris. After you make the file, you can run
the program by running the command: "./tetris".

The program implements 4 blocks from Tetris, the 'I', 'T', 'L', and square shapes. The shape
that will enter the game next is randomly generated after you drop your current shape down and
lock it in place.

You can use the arrow keys or 'w', 'a', 's', 'd', to control your current shape. There is collision
avoidance on each shape, so trying to move it out of bounds or rotating it on top of another shape
shouldn't work.
